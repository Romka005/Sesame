# Sesame
## 🍽️Сервис для заказа готовых здоровых рационов с доставкой на дом🍽️
👉[Посмотреть сайт с доставкой](https://romka005.github.io/Sesame/)👈

Этот сайт — удобный инструмент для тех, кто хочет питаться сбалансированно, но не имеет времени готовить. Пользователь может выбрать программу питания и посмотреть  меню на неделю, а после оформить заказ с доставкой.

## ✨ Функционал

- 🥑 Просмотр и выбор программ питания
- 🧮 Калькулятор суточной нормы калорий
- 🛒 Добавление рационов в корзину
- 📅 Выбор даты и времени доставки
- 📱 Адаптивный дизайн (работает на телефоне и компьютере)
