# Sesame
## 🍽️Сервис для заказа готовых здоровых рационов с доставкой на дом🍽️
👉[Посмотреть сайт с доставкой](https://romka005.github.io/Sesame/)👈

**Этот сайт — удобный инструмент для тех, кто хочет питаться сбалансированно, но не имеет времени готовить. Пользователь может выбрать программу питания, посмотреть меню на неделю и оформить заказ с доставкой.**

## 🍕 О проекте

Сервис доставки еды правильного питания (ПП), который помогает людям питаться вкусно и полезно без лишних хлопот. Всё просто: выбираешь день, смотришь меню, оформляешь доставку — и еда уже едет к тебе.

## ✨ Функционал

- 🥑 Просмотр и выбор программ питания
- 🧮 Калькулятор суточной нормы калорий
- 🛒 Добавление рационов в корзину
- 📅 Выбор даты и времени доставки
- 📱 Адаптивный дизайн (работает на телефоне и компьютере)
